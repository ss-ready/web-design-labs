# Лабораторные работы по HTML и CSS

В репозитории находятся лабораторные работы по дисциплине
«Веб-дизайн и верстка».

## Как скачать все лабораторные

1. Нажмите кнопку `Code`.
2. Выберите `Download ZIP`.
3. Распакуйте архив.
4. Откройте нужный HTML-файл в браузере.

## Как открыть лабораторную

Например:

`lab-01-html-basics.html`

Откройте файл двойным кликом.

Он откроется в браузере.

Для выполнения заданий файл можно открыть в:

- Visual Studio Code;
- WebStorm;
- Sublime Text;
- другом редакторе кода.
