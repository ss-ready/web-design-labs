Теоретическая часть

1. Основная идея

Flexbox работает через родительский элемент. После display:flex его непосредственные дети располагаются по flex-модели.

2. Как это устроено

gap задаёт расстояние между элементами. Это обычно удобнее, чем добавлять margin каждому ребёнку.

Проверка понимания: попробуйте своими словами объяснить преподавателю, что делает показанная конструкция и где она используется.

3. На что обратить внимание

justify-content управляет распределением по главной оси, align-items — по поперечной.

4. Практический смысл

flex-wrap: wrap разрешает перенос элементов на новую строку.

Разбор примеров

Ряд

Ряд
.cards {
  display: flex;
  gap: 16px;
}

Меню

Меню
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Перенос

Перенос
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
