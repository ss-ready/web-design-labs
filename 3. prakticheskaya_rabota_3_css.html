Практическая работа №3

Тема: Подключение CSS. Селекторы. Каскад и наследование. Единицы измерения. Блочная модель. Отступы, рамки и фон.

Цель: научиться подключать отдельный CSS-файл к HTML и пошагово оформлять страницу.

Что вы сделаете

  • создадите файлы index.html и style.css;
  • подключите CSS к HTML;
  • проверите, что стили действительно работают;
  • используете селекторы по тегу, классу и ID;
  • разберёте каскад и наследование;
  • поработаете с px и %;
  • оформите карточки через padding, margin, border, фон и скругление.

1. Создаём папку проекта

Шаг 1. Создайте папку, например practice-css.

Шаг 2. Внутри создайте два файла:

  • index.html
  • style.css
practice-css/
│
├── index.html
└── style.css
Проверьте расширения. Не должно быть index.html.txt или style.css.txt.

2. Создаём HTML-файл

Откройте index.html и вставьте:

<!DOCTYPE html>
<html lang="ru">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Учебные курсы</title>
</head>

<body>

    <h1>Учебные курсы</h1>

    <p>
        На этой странице собраны направления,
        которые мы изучаем на занятиях.
    </p>

</body>
</html>
Проверка: сохраните файл и откройте его в браузере. Должны появиться заголовок и абзац.

3. Как подключить CSS к HTML

Сейчас файл style.css существует, но HTML о нём ещё не знает.

Внутрь <head> добавьте:

<link rel="stylesheet" href="style.css">

Весь <head> будет выглядеть так:

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Учебные курсы</title>

    <link rel="stylesheet" href="style.css">
</head>
ЧастьЗначение
<link>Подключает внешний файл.
rel="stylesheet"Говорит браузеру, что подключается таблица CSS-стилей.
href="style.css"Путь к CSS-файлу.

Так как оба файла лежат рядом, путь очень простой:

href="style.css"

Если CSS лежит в папке css, путь будет:

<link rel="stylesheet" href="css/style.css">

4. Проверяем подключение CSS

Откройте style.css и напишите:

body {
    background-color: lightblue;
}

Сохраните CSS и обновите страницу.

Если фон стал голубым — CSS подключён правильно.

Если ничего не изменилось, проверьте:

  1. имя файла — style.css;
  2. оба файла лежат в одной папке;
  3. строка <link rel="stylesheet" href="style.css"> находится внутри <head>;
  4. оба файла сохранены;
  5. страница в браузере обновлена.

5. Первые стили

Замените тестовый CSS на:

body {
    font-family: Arial, sans-serif;
    background-color: #f2f2f2;
    color: #222222;
}

Здесь:

  • font-family — шрифт;
  • background-color — фон;
  • color — цвет текста.

6. Селектор по тегу

Добавьте в style.css:

h1 {
    color: darkblue;
    font-size: 36px;
}

p {
    font-size: 18px;
}

h1 выбирает все заголовки <h1>, а p — все абзацы.

Задание: измените цвет заголовка и размер текста на свои значения.

7. Добавляем карточки

После первого абзаца в HTML добавьте:

<div class="card">
    <h2>HTML</h2>
    <p>Язык разметки для создания структуры веб-страницы.</p>
</div>

<div class="card">
    <h2>CSS</h2>
    <p>Язык стилей для оформления веб-страницы.</p>
</div>

<div class="card special-card">
    <h2>JavaScript</h2>
    <p>Язык программирования для добавления интерактивности.</p>
</div>

8. Селектор по классу

В CSS точка означает класс:

.card {
    background-color: white;
}

Все элементы с class="card" получат белый фон.

В HTML: class="card". В CSS: .card.

9. Блочная модель

Блок удобно представлять как коробку:

MARGIN
    BORDER
        PADDING
            CONTENT

Измените стиль карточки:

.card {
    background-color: white;

    padding: 20px;
    margin: 20px 0;

    border: 1px solid #cccccc;
}
  • padding — отступ внутри;
  • margin — отступ снаружи;
  • border — рамка;
  • content — содержимое.

10. Эксперимент с padding и margin

Эксперимент 1. Поставьте:

padding: 50px;

Текст отодвинется от краёв карточки.

Эксперимент 2. Поставьте:

margin: 50px 0;

Карточки разойдутся дальше друг от друга.

После эксперимента верните:

padding: 20px;
margin: 20px 0;

11. Рамки и скругление

Добавьте:

.card {
    background-color: white;
    padding: 20px;
    margin: 20px 0;

    border: 1px solid #cccccc;
    border-radius: 10px;
}
Попробуйте border-radius: 0px, 20px, 40px и сравните.

12. Единицы измерения

Мы уже использовали px:

font-size: 18px;
padding: 20px;

Добавьте к body:

max-width: 900px;
margin: 0 auto;
padding: 20px;

Теперь содержимое ограничено по ширине и расположено по центру.

Попробуйте временно:

.card {
    width: 80%;
}

% — относительная единица: размер зависит от родительского элемента.

13. Селектор по ID

Измените заголовок в HTML:

<h1 id="main-title">Учебные курсы</h1>

Добавьте в CSS:

#main-title {
    text-align: center;
}
Запомните:
класс — .card
ID — #main-title

14. Каскад

Добавьте:

h2 {
    color: blue;
}

.special-card h2 {
    color: red;
}

Обычные h2 станут синими, а заголовок внутри .special-card — красным.

Более конкретное правило получает преимущество.

Теперь временно попробуйте:

p {
    color: green;
}

p {
    color: purple;
}

При одинаковой специфичности сработает правило, написанное позже.

После эксперимента удалите эти два временных правила.

15. Наследование

Свойства вроде цвета текста и шрифта часто наследуются от родителя.

Например:

body {
    font-family: Georgia, serif;
    color: #333333;
}

Многие вложенные элементы автоматически получат этот шрифт и цвет.

Попробуйте поменять шрифт у body и посмотрите, сколько элементов изменилось сразу.

16. Специальная карточка

У третьего блока два класса:

class="card special-card"

Добавьте:

.special-card {
    background-color: #fff3cd;
    border: 2px solid #e0a800;
}

К ней одновременно применяются стили .card и .special-card.

17. Добавляем кнопку-ссылку

В каждую карточку после абзаца добавьте:

<a class="button" href="#">Подробнее</a>

В CSS:

.button {
    display: inline-block;

    background-color: darkblue;
    color: white;

    padding: 10px 16px;
    margin-top: 10px;

    border-radius: 6px;
    text-decoration: none;
}
