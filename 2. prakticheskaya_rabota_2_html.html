Практическая работа №2

Тема: Структура HTML-документа и основные элементы

Цель: научиться создавать простую HTML-страницу и использовать основные теги.

Задание

Создайте простую веб-страницу на тему «Моя учебная страница».

На странице должны быть:

  • главный заголовок;
  • не менее двух подзаголовков;
  • несколько абзацев текста;
  • маркированный список;
  • нумерованный список;
  • ссылка на внешний сайт;
  • изображение;
  • семантические элементы страницы.

Часть 1. Создание структуры документа

Создайте файл index.html и добавьте базовую структуру HTML-документа. 

<!DOCTYPE html>
<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Моя учебная страница</title>
</head>

<body>

</body>

</html>

Проверьте, что файл сохранён с расширением .html, а не .txt.

Часть 2. Семантическая структура

Внутри <body> создайте:

  • <header> — верхняя часть страницы;
  • <nav> — навигация;
  • <main> — основное содержимое;
  • <section> — отдельные смысловые разделы;
  • <footer> — нижняя часть страницы.

Пример:

<body>

    <header>
        ...
    </header>

    <nav>
        ...
    </nav>

    <main>

        <section>
            ...
        </section>

    </main>

    <footer>
        ...
    </footer>

</body>

Часть 3. Заголовки и абзацы

Добавьте:

  1. один главный заголовок <h1>;
  2. минимум два заголовка второго уровня <h2>;
  3. не менее трёх абзацев <p>.

Например:

<h1>Моя учебная страница</h1>

<h2>Обо мне</h2>

<p>
    Меня зовут Иван. Я учусь в колледже.
</p>

<p>
    Мне интересны информационные технологии.
</p>

Часть 4. Списки

Создайте маркированный список «Мои интересы». 

<ul>
    <li>Компьютеры</li>
    <li>Музыка</li>
    <li>Спорт</li>
</ul>

Создайте нумерованный список «Что я хочу изучить». 

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Часть 5. Ссылка

Добавьте ссылку на полезный образовательный ресурс. 

<a href="https://example.com">
    Перейти на сайт
</a>

Измените адрес и текст ссылки самостоятельно.

Часть 6. Изображение

Сохраните рядом с HTML-файлом любое подходящее изображение. Например:

photo.jpg

Добавьте его на страницу:

<img src="photo.jpg" alt="Описание изображения" width="400">

Атрибут alt должен описывать, что находится на изображении.

Часть 7. Навигация

Внутри <nav> добавьте несколько ссылок-заглушек: 

<nav>
    <a href="#">Главная</a>
    <a href="#">Обо мне</a>
    <a href="#">Контакты</a>
</nav>

Часть 8. Нижняя часть страницы

Внутри <footer> добавьте имя автора и год. 

<footer>
    <p>Автор: Иван Иванов, 2026</p>
</footer>

Итоговая структура

В результате ваша страница должна примерно иметь такую структуру:

<body>

    <header>
        <h1>Моя учебная страница</h1>
    </header>

    <nav>
        ссылки
    </nav>

    <main>

        <section>
            <h2>Обо мне</h2>
            абзацы
        </section>

        <section>
            <h2>Мои интересы</h2>
            список
        </section>

        <section>
            <h2>Что я хочу изучить</h2>
            список
        </section>

        <section>
            ссылка и изображение
        </section>

    </main>

    <footer>
        информация об авторе
    </footer>

</body>

Дополнительное задание

Для тех, кто закончил раньше:

  1. Добавьте ещё один раздел <section>.
  2. Добавьте заголовок <h3>.
  3. Добавьте второе изображение.
  4. Сделайте ссылку на другую HTML-страницу.
  5. Создайте файл contacts.html и свяжите две страницы ссылками.

Что нужно сдать

  • файл index.html;
  • используемое изображение;
  • дополнительный файл contacts.html, если выполнено дополнительное задание.

Критерии проверки

  1. HTML-документ имеет правильную структуру.
  2. Используются семантические теги.
  3. Есть заголовки и абзацы.
  4. Есть оба вида списков.
  5. Ссылка работает.
  6. Изображение отображается.
  7. У изображения заполнен alt.
  8. Теги правильно вложены и закрыты.
  9. Страница открывается в браузере без явных ошибок.
